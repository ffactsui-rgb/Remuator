Версия 12.1: проверка выполнена

Полная сборка ESP32-S3 N16R8, Arduino-ESP32 3.3.0, Flash 16M, OPI PSRAM, HWCDC/CDC on boot.
Sketch uses 1349811 bytes (32%) of program storage space. Maximum is 4194304 bytes.
Global variables use 87404 bytes (26%) of dynamic memory, leaving 240276 bytes for local variables. Maximum is 327680 bytes.

Успешны нативные тесты управления программой/восстановления, UART, RTC, калибровки X/Y, удержания, тестового движения и перезагрузки.
Новые тесты bootstrap: пустая/частичная/полная файловая система, файлы нулевого размера, каталог вместо файла, маршруты встроенной настройки, Wi-Fi SSID/пароль, отсутствие пароля в статусе, Basic Auth менеджера, блокировка при движении, выбор встроенного/файлового менеджера, проверка полностью стёртого раздела и отказ при ошибке чтения.
DOM-тесты выполняют обе встроенные страницы без внешних ресурсов: сохранение Wi-Fi, очистка поля пароля, переход с AP к менеджеру, ссылка STA, список пустой FS, загрузка файла и ссылка на главную при готовом комплекте. Пройдены прежние DOM-тесты версии 12.0 и синтаксические проверки обычного и встроенного JavaScript.
Исходные CSV и partitions.csv совпадают с 12.0. Аппаратные испытания не выполнялись.
