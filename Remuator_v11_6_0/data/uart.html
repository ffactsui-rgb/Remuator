Фактическая проверка UART

Проверяет IOIN и IFCNT каждого драйвера и ищет TMC2209 по адресам 1–3. Работает только после полной остановки. Адрес 0 не сканируется: он зарезервирован для TMC2208 и два ответа могут конфликтовать.

Диагностика ещё не запущена.

Общая шина UART

TX GPIO21, RX GPIO47. Выберите установленные драйверы и адреса, соответствующие перемычкам. По умолчанию для новой платы: Y — TMC2208 (адрес 0), Z — TMC2209 (адрес 1). Настройки применяются при остановленной программе и двигателях.

TMC2208: адрес всегда 0; MS1/MS2 не выбирают UART-адрес. TMC2209: адрес = MS1 + 2×MS2; 0 — GND, 1 — 3,3 В. Изменение здесь не переставляет физические перемычки. На общей шине адреса должны различаться.

Ток, удержание, микрошаги, StealthChop/SpreadCycle и PWM доступны обеим моделям. StallGuard и CoolStep у TMC2209 отключены; Z работает без концевиков. Для TMC2208 предел формы — 1400 мА RMS, для TMC2209 — 2000 мА RMS; допустимый ток конкретного модуля зависит от его охлаждения. Расчёт тока рассчитан на Rsense 0,11 Ом.

Профиль «Момент и скорость» (значения по умолчанию)

spreadCycle (StealthChop выключен), RMS 900 мА для осторожного первого включения, удержание 50%, 16 микрошагов с интерполяцией 256, TOFF 5, blank 24, hysteresis start 4, end 0. Это профиль динамической работы, не универсально максимальный ток: для более высокого момента ток подбирают по паспортному фазному току двигателя, охлаждению драйвера и отсутствию пропуска шагов.

При spreadCycle параметры PWM offset/gradient/frequency/regulation/limit, autoscale и autograd не управляют этим режимом; они предназначены для StealthChop. Настройки, уже сохранённые в NVS, имеют приоритет над умолчаниями прошивки. Вводите параметры вручную только при остановленных двигателях.
